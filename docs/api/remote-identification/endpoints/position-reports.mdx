# Position Reports

A position report is one received Remote ID message: where the aircraft was,
when, how it was received, and the raw decoded payload. Each report is stored as
two rows, a `message` (payload, hash, signature, verification, receiver) and a
`position_report` (time, coordinates, altitude, session). The API always reads
and writes them together as one flat object.

`payload_hash` defaults to the SHA-256 of the payload JSON. Filter on it to
detect the same message received by several receivers.
