# CAA Registry API

The CAA Registry is the system of record for who may fly and with what:
organizations, their users and admins, approved operators, registered UA
aircraft, Remote ID records, and custom properties attached to them. Every
write is audited.

It is a Fastify 5 service written in TypeScript on Bun, backed by PostgreSQL
through Drizzle ORM, with ZITADEL OIDC tokens for authentication. For service
internals see the [module architecture](../../modules/caa-registry/overview).

## Environment

Every endpoint card on these pages has a **Try it** console. Set the base URL
and a token once here, and every console for this API uses them. You can also
download a Postman collection generated from these pages.

<ApiEnvironment api="caa-registry" endpoints={allEndpoints} />

:::note[Browser requests]

The CAA Registry does not send CORS headers. The **Try it** console works only
when the docs and the API share an origin, or through a proxy. Otherwise, copy
the generated cURL command and run it from a terminal.

:::

## What changed in this version

- **The UAS layer is gone.** UA aircraft now belong directly to an organization
  through `org_id`. The `/uas` routes, `uas.*` permissions, and the
  `/lookup/uas/...` route no longer exist.
- **New resources:** [Remote IDs](./endpoints/remote-ids),
  [organization admins](./endpoints/organizations#list-organization-admins), and
  [custom properties](./endpoints/custom-properties) for operators,
  organizations, and aircraft.
- **Generic filtering:** every table has a [`POST .../filter`](./endpoints/filters)
  endpoint with typed operators, `match: any`, sorting, and `all: true`.
- **Ownership guards:** `PUT` and `DELETE` on operators and aircraft accept
  `expected_org_id` as a compare-and-set check.

## Endpoint families

| Family | Base routes | Purpose |
| --- | --- | --- |
| [Reference data](./endpoints/reference-data) | `/operator-types`, `/user-types` | Classification values. |
| [Organizations](./endpoints/organizations) | `/organizations`, `/organization-admins` | Registry participants and their admins. |
| [Users](./endpoints/users) | `/users` | Registry users and national ids. |
| [ZITADEL integrations](./endpoints/zitadel-integrations) | `/integrations/zitadel/...` | Signed identity lifecycle events. |
| [Operators](./endpoints/operators) | `/operators` | Approved operators. |
| [UA aircraft](./endpoints/ua-aircraft) | `/ua` | Registered aircraft. |
| [Remote IDs](./endpoints/remote-ids) | `/remote-ids` | Remote ID certificate records. |
| [Custom properties](./endpoints/custom-properties) | `/*-property-names`, `/*-properties` | Typed, validated extra fields. |
| [Lookup and search](./endpoints/lookup-and-search) | `/lookup/ua/...`, `/search` | Operational lookup and cross-entity search. |
| [Filters](./endpoints/filters) | `/<resource>/filter` | Structured queries on any table. |
| [Audit](./endpoints/audit) | `/audit`, `/<entity>/:id/history` | Write history. |
| [System jobs](./endpoints/system-jobs) | `/system/jobs` | Background ZITADEL reconciliation. |
