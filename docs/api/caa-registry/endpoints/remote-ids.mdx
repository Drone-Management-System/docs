# Remote IDs

Remote ID records hold the Remote ID certificate data the CAA tracks for an
organization: a reference, the certificate subject, a validity window, and a
status. They map to `caa_registry_api.remote_id` and are deleted with their
organization.

The removed `authority_id` filter returns `remote_id_authority_filter_removed`.
