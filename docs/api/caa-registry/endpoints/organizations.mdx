# Organizations

Organizations are the registry's top-level owners: CAAs, USSs, operators,
service providers, and everyone else. Operators, UA aircraft, Remote ID
records, and organization admins all hang off an organization. They map to
`caa_registry_api.organization`.

<EndpointTable endpoints={[...Object.values(organizations), ...Object.values(organizationAdmins)]} />

## Organization object

| Field | Type | Notes |
| --- | --- | --- |
| `org_id` | uuid | Generated by the database. |
| `org_name` | string | Unique. |
| `organization_kind` | enum | `CAA`, `USS`, `OPERATOR`, `SERVICE_PROVIDER`, or `OTHER`. |
| `contact_email` | string \| null | |
| `contact_phone` | string \| null | |
| `country_code` | string \| null | Upper-case. |
| `created_at`, `updated_at` | timestamp | ISO 8601, UTC. |

## Organization admins

An organization admin link marks a registry user as an administrator of one
organization. A user can administer several organizations, but each
organization and user pair can appear only once. Links are removed
automatically when either the organization or the user is deleted.
