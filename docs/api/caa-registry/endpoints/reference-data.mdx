# Reference Data

Operator types and user types are small lookup tables that classify operators
and registry users. Their ids are smallints chosen by the client, so ids can
be kept stable across environments.

Deleting a type does not delete the operators or users that use it: their
`operator_type_id` or `user_type_id` is set to `null`.
