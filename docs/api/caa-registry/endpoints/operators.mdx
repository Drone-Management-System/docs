# Operators

Operators are organizations approved by the CAA to fly. Each operator belongs
to one organization and can name a primary user and an operator type. The
approval reference and validity window record the CAA approval itself. They
map to `caa_registry_api.operator`.

Operators can carry [custom properties](./custom-properties), such as an
insurance expiry date.
