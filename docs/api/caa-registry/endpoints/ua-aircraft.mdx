# UA Aircraft

UA records are individual registered aircraft. Each aircraft belongs directly
to an organization through `org_id`, and is identified by a unique
`registration_id` (the CAA registration) and a unique `serial_number`. They map
to `caa_registry_api.ua`.

:::info[Migrating from UAS records]

Earlier versions grouped aircraft under UAS registrations owned by operators.
That layer was removed: there is no `uas_id`, no `/uas` route, and aircraft no
longer reference an operator. Requests that still send `uas_id` or
`operator_id` are rejected with `ua_relationship_filter_removed` (list) or
`payload_invalid` (writes).

:::
