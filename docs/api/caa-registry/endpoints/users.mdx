# Registry Users

Registry users are people known to the CAA: remote pilots, operator staff,
and organization admins. They map to `caa_registry_api.user`.

A user can be created directly, or arrive from ZITADEL through the
[integration endpoints](./zitadel-integrations) or a
[sync job](./system-jobs). ZITADEL-linked users carry `zitadel_user_id`, a
`zitadel_status` of `active` or `deleted`, and sync timestamps. These fields are
read-only here.

National ids are optional, but must be complete: number, issuing country, and
document type are either all set or all `null`. The combination is unique
across users.
