# Volume Properties

Volume properties attach typed custom fields to 4D volumes, such as a noise
limit or a maximum aircraft class. First define a property, then assign values
to volumes. Values are always strings, validated against the definition's
`data_type` and `domain_values`.

| `data_type` | Value example |
| --- | --- |
| `string` | `"CLASS_C"` |
| `integer` / `number` | `"65"`, `"2.5"` |
| `boolean` | `"true"` |
| `date` / `datetime` | `"2026-06-10"`, `"2026-06-10T06:00:00Z"` |
| `json` | `"{\"bands\":[2.4,5.8]}"` |

Values are included in every 4D volume read under `properties`, each with its
`property_name` definition.
