# Volumes

Volumes are the geometry behind every constraint:

- A **3D volume** is a GeoJSON footprint with an altitude band.
- A **4D volume** adds time (a validity window, or `permanent`), a status, a
  default accessibility, and an optional rule. Each 4D volume is built on its
  own 3D volume.
- A **link** attaches a 4D volume to a constraint.

Most clients create volumes inline through the
[constraint endpoints](./airspace-constraints#attaching-a-volume). Use these
endpoints to edit geometry or time windows directly.

:::danger[Deletes cascade]

Deleting a 3D or 4D volume also deletes the constraints linked to it. Deleting
the 3D volume under an area also deletes the flight corridors that use that
area. Check `GET /airspace-constraint-volume-links/filter?volume_4d_id=...`
before deleting.

:::
