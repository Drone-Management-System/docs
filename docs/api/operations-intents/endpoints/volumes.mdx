# Volumes

Volumes describe where and when an operation flies. A **3D volume** is a
GeoJSON footprint with an altitude band. A **4D volume** adds a validity window
and a status, and points at one 3D volume. An intent can use several 4D volumes
(see [intent volume links](./operational-intents#intent-volume-links)), and
volumes can be created inline in a [package](./operational-intents#create-intent-package).

Unlike in Constraint Management, these volumes always have a time window, and
deleting one does not cascade. Deletes fail with `*_has_linked_records` while
something still references the volume.
