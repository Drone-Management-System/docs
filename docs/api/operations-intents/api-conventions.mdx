# API Conventions

This page documents conventions shared across Operations Intents endpoints.

## Content Type

Write endpoints expect JSON request bodies:

```http
Content-Type: application/json
Accept: application/json
```

## Pagination

Most list endpoints use offset pagination:

| Query parameter | Default | Minimum | Maximum |
| --- | --- | --- | --- |
| `limit` | `50` | `1` | `200` |
| `offset` | `0` | `0` | `100000` |

The response shape is:

```json
{
  "items": [],
  "limit": 50,
  "offset": 0,
  "has_more": false
}
```

## Filtering

`GET /operational-intents/filter` supports filters over linked 4D volumes:

| Query parameter | Notes |
| --- | --- |
| `active` | Boolean filter against linked 4D volume `status_code`. |
| `current_time` or `current` | Boolean filter for whether linked 4D volumes include current server time. |
| `start_time` or `start` | Start of an overlap time range. Must be paired with end. |
| `end_time` or `end` | End of an overlap time range. Must be after start. |
| `latitude` or `lat` | Position latitude, from `-90` to `90`. |
| `longitude`, `lng`, or `lon` | Position longitude, from `-180` to `180`. |
| `buffer_m` | Optional position buffer in meters, from `0` to `1000000`. |

`current_time` cannot be combined with an explicit start/end time range.

## Validation Contexts

Supported validation contexts are `CREATE`, `UPDATE`, `APPROVAL_REQUEST`,
`ACTIVATION`, and `REVALIDATION`.

## Error Envelope

Application errors use:

```json
{
  "detail": "machine_readable_detail"
}
```

| Status | Typical cause |
| --- | --- |
| `400` | Missing required field, invalid query, invalid UUID, invalid geometry, invalid date, or invalid numeric value. |
| `401` | Missing or invalid authentication when auth is enabled. |
| `403` | Valid token but missing permission when a route asserts permissions. |
| `404` | Requested record not found. |
| `409` | Unique or foreign-key conflict. |
| `501` | A validation dependency table is unavailable in the connected database. |
| `500` | Unhandled server error. |
