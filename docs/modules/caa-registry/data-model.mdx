# Data Model

The CAA Registry API maps directly to PostgreSQL tables defined in
`src/db/schema.ts` and created by the migrations in `drizzle/` (through
`0011_remove_remote_id_authority.sql` at the time of writing).

## Schemas

| Schema | Purpose |
| --- | --- |
| `caa_registry_api` | Registry tables owned by this service. |
| `public` | Shared `audit_log` table used for write history. |

## Organization Kinds

`organization.organization_kind` must be one of:

| Value | Typical use |
| --- | --- |
| `CAA` | Civil aviation authority. |
| `USS` | UAS service supplier. |
| `OPERATOR` | UAS operator organization. |
| `SERVICE_PROVIDER` | Service provider organization. |
| `OTHER` | Fallback when the organization does not fit another category. |

The API defaults omitted organization kind values to `OTHER`.

## `caa_registry_api.operator_type`

Reference table for classifying operators.

| Column | Type | Required | Notes |
| --- | --- | --- | --- |
| `operator_type_id` | `smallint` | Yes | Primary key supplied by client. |
| `code` | `text` | Yes | Unique code. |
| `description` | `text` | No | Human-readable description. |

## `caa_registry_api.user_type`

Reference table for classifying registry users.

| Column | Type | Required | Notes |
| --- | --- | --- | --- |
| `user_type_id` | `smallint` | Yes | Primary key supplied by client. |
| `code` | `text` | Yes | Unique code. |
| `description` | `text` | No | Human-readable description. |

## `caa_registry_api.organization`

Organizations represent CAAs, USSs, operators, service providers, and other
registry participants.

| Column | Type | Required | Notes |
| --- | --- | --- | --- |
| `org_id` | `uuid` | Yes | Primary key generated by the database. |
| `org_name` | `text` | Yes | Unique organization name. |
| `organization_kind` | `text` | Yes | Enum-like value with database check constraint. Defaults to `OTHER`. |
| `contact_email` | `text` | No | Optional contact email. |
| `contact_phone` | `text` | No | Optional contact phone. |
| `country_code` | `text` | No | Uppercased by API when supplied. |
| `created_at` | `timestamp with time zone` | Yes | Defaults to `now()`. |
| `updated_at` | `timestamp with time zone` | Yes | Defaults to `now()`, updated on `PUT`. |

Indexes and constraints:

| Name | Purpose |
| --- | --- |
| `organization_org_name_unique` | Prevents duplicate organization names. |
| `organization_kind_idx` | Speeds filtering by organization kind. |
| `organization_kind_valid` | Restricts `organization_kind` to supported values. |

## `caa_registry_api.user`

Registry users represent people in the registry. A user can belong to an
organization and a user type, but both links are optional and set to `null`
if the referenced row is deleted.

| Column | Type | Required | Notes |
| --- | --- | --- | --- |
| `user_id` | `uuid` | Yes | Primary key generated by the database. |
| `org_id` | `uuid` | No | References `organization.org_id`, `on delete set null`. |
| `user_type_id` | `smallint` | No | References `user_type.user_type_id`, `on delete set null`. |
| `zitadel_user_id` | `text` | No | Legacy compatibility mirror of the ZITADEL provider user ID. New provider links are stored in `user_identity`. |
| `zitadel_status` | `text` | Yes | Identity lifecycle status. One of `active` or `deleted`. Defaults to `active`. |
| `zitadel_deleted_at` | `timestamp with time zone` | No | Time ZITADEL reported `user.removed`. |
| `zitadel_last_synced_at` | `timestamp with time zone` | No | Last time identity lifecycle state was synced from ZITADEL. |
| `national_id_number` | `text` | No | Generic national identity number. |
| `national_id_country_code` | `text` | No | Issuing country code, uppercased by API. |
| `national_id_type` | `text` | No | Identifier type, lowercased by API, such as `emirates_id`, `aadhaar`, `national_id`, or `other`. |
| `full_name` | `text` | Yes | Required display name. |
| `email` | `text` | Yes | Unique and lowercased by API. |
| `phone` | `text` | No | Optional phone. |
| `created_at` | `timestamp with time zone` | Yes | Defaults to `now()`. |
| `updated_at` | `timestamp with time zone` | Yes | Defaults to `now()`, updated on `PUT`. |

Indexes and constraints:

| Name | Purpose |
| --- | --- |
| `user_email_unique` | Prevents duplicate user emails. |
| `user_zitadel_user_id_unique` | Prevents duplicate ZITADEL identity links. |
| `user_org_id_idx` | Speeds organization filtering. |
| `user_user_type_id_idx` | Speeds user type filtering. |
| `user_email_idx` | Speeds email search and lookup paths. |
| `user_zitadel_status_idx` | Speeds active/deleted identity lifecycle filtering. |
| `user_zitadel_status_valid` | Restricts `zitadel_status` to `active` or `deleted`. |
| `user_national_id_unique` | Prevents duplicate national ID triples across country, type, and number. |
| `user_national_id_complete` | Requires all national ID fields to be supplied together or all omitted. |

## `caa_registry_api.user_identity`

User identities link a registry user to an external authentication provider.
This keeps CAA Registry portable across ZITADEL, Keycloak, Auth0, or any future
OIDC provider.

| Column | Type | Required | Notes |
| --- | --- | --- | --- |
| `user_identity_id` | `uuid` | Yes | Primary key generated by the database. |
| `user_id` | `uuid` | Yes | References `user.user_id`, `on delete cascade`. |
| `provider` | `text` | Yes | Provider key such as `zitadel`, `keycloak`, or `auth0`. |
| `provider_user_id` | `text` | Yes | Stable provider subject/user ID. |
| `status` | `text` | Yes | `active` or `deleted`. |
| `metadata` | `jsonb` | No | Provider-specific metadata used for diagnostics or sync context. |
| `linked_at` | `timestamp with time zone` | Yes | First link time. Defaults to `now()`. |
| `last_synced_at` | `timestamp with time zone` | No | Last successful provider sync. |
| `deleted_at` | `timestamp with time zone` | No | Provider deletion time when known. |
| `created_at` | `timestamp with time zone` | Yes | Defaults to `now()`. |
| `updated_at` | `timestamp with time zone` | Yes | Defaults to `now()`. |

Indexes and constraints:

| Name | Purpose |
| --- | --- |
| `user_identity_provider_user_unique` | Prevents one provider subject from linking to multiple registry users. |
| `user_identity_user_id_idx` | Speeds lookup of identities for one registry user. |
| `user_identity_provider_idx` | Speeds provider-level sync and diagnostics. |
| `user_identity_status_idx` | Speeds active/deleted identity filtering. |
| `user_identity_provider_not_blank` | Prevents blank provider keys. |
| `user_identity_provider_user_id_not_blank` | Prevents blank provider user IDs. |
| `user_identity_status_valid` | Restricts status to `active` or `deleted`. |

## `caa_registry_api.operator`

Operators represent approved operating entities linked to organizations.

| Column | Type | Required | Notes |
| --- | --- | --- | --- |
| `operator_id` | `uuid` | Yes | Primary key generated by the database. |
| `org_id` | `uuid` | Yes | References `organization.org_id`, `on delete restrict`. |
| `primary_user_id` | `uuid` | No | References `user.user_id`, `on delete set null`. Must belong to the same org when the user has an org. |
| `operator_type_id` | `smallint` | No | References `operator_type.operator_type_id`, `on delete set null`. |
| `approval_reference` | `text` | No | Unique approval reference. |
| `approval_valid_from` | `date` | No | Date-only string in API. |
| `approval_valid_to` | `date` | No | Must be on or after `approval_valid_from` when both exist. |
| `created_at` | `timestamp with time zone` | Yes | Defaults to `now()`. |
| `updated_at` | `timestamp with time zone` | Yes | Defaults to `now()`, updated on `PUT`. |

Indexes and constraints:

| Name | Purpose |
| --- | --- |
| `operator_approval_reference_unique` | Prevents duplicate approval references. |
| `operator_org_id_idx` | Speeds organization filtering. |
| `operator_primary_user_id_idx` | Speeds primary user joins. |
| `operator_operator_type_id_idx` | Speeds operator type filtering. |
| `operator_approval_dates_valid` | Enforces valid approval windows. |

## `caa_registry_api.ua`

UA records are individual registered aircraft. Since migration
`0009_ua_organization_ownership.sql`, each aircraft belongs directly to an
organization; the `uas` table and the `ua.uas_id` column no longer exist.

| Column | Type | Required | Notes |
| --- | --- | --- | --- |
| `ua_id` | `uuid` | Yes | Primary key generated by the database. |
| `org_id` | `uuid` | Yes | References `organization.org_id`, `on delete restrict`. |
| `registration_id` | `text` | Yes | Unique CAA registration id. |
| `serial_number` | `text` | Yes | Unique manufacturer serial number. |
| `aircraft_type` | `text` | Yes | Aircraft category. |
| `model_name` | `text` | No | Model name. |
| `propulsion_type` | `text` | No | Propulsion type. |
| `remote_id_capable` | `boolean` | Yes | Defaults to `true`. |
| `mass_kg` | `numeric(8,2)` | No | Non-negative. |
| `max_airspeed_mps` | `numeric(7,2)` | No | Non-negative. |
| `max_altitude_m` | `numeric(8,2)` | No | Non-negative. |
| `endurance_minutes` | `integer` | No | Positive. |
| `created_at`, `updated_at` | `timestamp with time zone` | Yes | Default `now()`. |

Constraints: `ua_registration_id_unique`, `ua_serial_number_unique`,
`ua_org_id_idx`, and non-negative or positive checks on the numeric columns.

## `caa_registry_api.remote_id`

Remote ID certificate records owned by an organization.

| Column | Type | Required | Notes |
| --- | --- | --- | --- |
| `remote_id_id` | `uuid` | Yes | Primary key. |
| `org_id` | `uuid` | Yes | References `organization.org_id`, `on delete cascade`. |
| `reference` | `text` | Yes | Certificate reference. |
| `subject_name` | `text` | Yes | Certificate subject. |
| `valid_from`, `valid_to` | `timestamp with time zone` | Yes | `remote_id_valid_time_chk` requires `valid_to > valid_from`. |
| `status_code` | `text` | Yes | Defaults to `ACTIVE`. |

The `authority_id` column was removed in `0011_remove_remote_id_authority.sql`.

## `caa_registry_api.organization_admin`

Links registry users who administer an organization.

| Column | Type | Required | Notes |
| --- | --- | --- | --- |
| `organization_admin_id` | `uuid` | Yes | Primary key. |
| `org_id` | `uuid` | Yes | References `organization.org_id`, `on delete cascade`. |
| `user_id` | `uuid` | Yes | References `user.user_id`, `on delete cascade`. |
| `created_at`, `updated_at` | `timestamp with time zone` | Yes | Default `now()`. |

`organization_admin_org_user_unique` allows each pair once.

## Custom property tables

Operators, organizations, and aircraft each have a definition catalog and a
value table with the same shape.

| Owner | Definitions | Values | Parent column |
| --- | --- | --- | --- |
| Operator | `operators_properties_names` | `operators_properties` | `operator_id` |
| Organization | `organization_properties_names` | `organization_properties` | `org_id` |
| UA | `ua_properties_names` | `ua_properties` | `ua_id` |

Definition columns:

| Column | Type | Notes |
| --- | --- | --- |
| `<table>_id` | `uuid` | Primary key, for example `operators_properties_names_id`. |
| `name` | `text` | Unique within the catalog. |
| `description` | `text` | Optional. |
| `data_type` | `text` | `string`, `integer`, `number`, `boolean`, `date`, `datetime`, or `json`. Default `string`. |
| `is_required`, `is_unique` | `boolean` | Default `false`. |
| `domain_values` | `jsonb` | `{"kind":"set",...}` or `{"kind":"range",...}`, validated in `src/lib/property-validation.ts`. |

Value columns: a primary key, the parent id (`on delete cascade`), the
definition id (`on delete cascade`), and `value` as `text`. Type, domain,
requiredness, and uniqueness are enforced by the API (`src/lib/property-write.ts`)
rather than by the database. Writes lock the definition row first, so value
writes and definition edits are serialized.

## `public.audit_log`

The audit table records every mutable registry operation.

| Column | Type | Required | Notes |
| --- | --- | --- | --- |
| `audit_id` | `uuid` | Yes | Primary key generated by the database. |
| `entity_type` | `text` | Yes | For example `organization`, `organization_admin`, `user`, `operator`, `ua`, `remote_id`, `*_property`, `*_property_name`, `operator_type`, `user_type`. |
| `entity_id` | `text` | Yes | Entity id as text. |
| `action` | `text` | Yes | `create`, `update`, `delete`, `update_national_id`, or `zitadel_sync_*`. |
| `actor` | `text` | Yes | Email, username, subject, or `system`. |
| `correlation_id` | `text` | No | Column exists but route handlers do not currently populate it. |
| `created_at` | `timestamp with time zone` | Yes | Defaults to `now()`. |
| `before_json` | `jsonb` | No | Snapshot before update or delete. |
| `after_json` | `jsonb` | No | Snapshot after create, update, or delete. |

Indexes: `audit_log_entity_idx` (entity history) and
`audit_log_created_at_idx` (recent listing).

## Relationship Summary

| Parent | Child | Delete behavior |
| --- | --- | --- |
| `organization` | `user` | User `org_id` is set to `null`. |
| `organization` | `operator` | Restricted. The API currently surfaces this as `500`. |
| `organization` | `ua` | Restricted. The API returns `409 organization_reference_conflict`. |
| `organization` | `remote_id`, `organization_admin`, `organization_properties` | Cascade. |
| `user` | `user_identity`, `organization_admin` | Cascade. |
| `user` | `operator.primary_user_id` | Set to `null`. |
| `user_type` | `user` | `user_type_id` is set to `null`. |
| `operator_type` | `operator` | `operator_type_id` is set to `null`. |
| `operator` | `operators_properties` | Cascade. |
| `ua` | `ua_properties` | Cascade. |
| `*_properties_names` | `*_properties` | Cascade. |
